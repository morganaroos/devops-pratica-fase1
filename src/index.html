DevOps na Prática

Projeto Fase 1 - Configuração e Automação Inicial

Este projeto demonstra a aplicação de conceitos de DevOps utilizando integração contínua, testes automatizados e infraestrutura como código.

Funcionalidades demonstradas

  • Site estático versionado no GitHub
  • Pipeline de CI com GitHub Actions
  • Testes automatizados
  • Infraestrutura como Código com Terraform
  • Provisionamento de bucket S3 na AWS
